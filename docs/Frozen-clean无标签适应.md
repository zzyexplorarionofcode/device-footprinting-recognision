# Frozen-clean + 无标签适应

## 协议

- 源域：防御前 clean warmup，4000 条带标签 flow；
- 目标域：Full New5 防御后 150 观测日 Blind；
- 目标域 **0 标签**，只使用无标签特征；
- 目标标签只用于最终 BA 评分，不参与适应、阈值、聚类映射；
- 同一 D/C 特征、同一 LR/RF 分类器。

## 方法

| 方法 | 说明 |
| --- | --- |
| Clean-only | clean 训练后冻结，直接测目标 |
| CORAL | 用目标无标签特征对齐二阶统计量 |
| Pseudo-label | 高置信目标伪标签自训练 3 轮 |
| KMeans-Hungarian | 目标聚类后按源类中心做匈牙利匹配 |

## 结果

| 视图/模型 | Clean-only | CORAL | Pseudo-label | KMeans-Hungarian |
| --- | ---: | ---: | ---: | ---: |
| D/LR | 0.149 | 0.176 | 0.158 | 0.110 |
| D/RF | 0.178 | 0.156 | 0.178 | 0.110 |
| C/LR | 0.398 | 0.252 | 0.366 | 0.244 |
| C/RF | 0.395 | 0.251 | 0.254 | 0.244 |

## 解释

1. **CORAL 没有帮助**：D/LR 略升 0.027，但 D/RF、C/LR、C/RF 全部下降；全局二阶对齐不适合这种类条件漂移。
2. **伪标签基本无效**：D/RF 持平，C/LR 0.398→0.366；高置信伪标签仍被源域偏差主导。
3. **KMeans-Hungarian 最差**：0.11–0.24；无标签聚类无法恢复类别语义，匈牙利匹配也不足以对齐。
4. **无标签适应没有突破 Frozen-clean**：说明残余不是“模型没适应”，而是目标域中存在源域模型无法利用/无法对齐的稳定特征，或源域模型本身偏差太大。

## 结论

> 在 Full New5、150 日、0 目标标签下，CORAL、伪标签、KMeans 对齐都没有稳定超过 Clean-only；无标签适应不能作为有效攻击基线。下一步应做特征组拆解，定位跨防御稳定的可观测信息，而不是继续加 UDA 方法。

## 限制

- 仅 seed 0；
- 目标域为 Full New5，不含 Weakener-only；
- C 视图绝对值与标签矩阵的 Frozen-clean 存在差异，需在同一特征/样本实现下复核；本表只作方法内相对比较；
- 未做深度域适应、对抗训练等更强方法。
