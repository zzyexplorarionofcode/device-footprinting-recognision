# Frozen-clean + 无标签适应（审计修正版）

## 协议

- 源域：防御前 clean warmup，4000 条带标签 flow；
- 目标域：Full New5 防御后 150 观测日 Blind；
- 目标域 0 标签；
- 目标标签只用于最终评分；
- 同一 D/C 特征、同一 LR/RF；
- BA 采用“每日 BA 再对 150 天平均”，与标签矩阵一致。

## 方法

| 方法 | 说明 |
| --- | --- |
| Clean-only | clean 训练后冻结，直接测目标 |
| CORAL | 用目标无标签特征对齐二阶统计量 |
| Pseudo-label | 高置信目标伪标签自训练 3 轮 |
| KMeans-Hungarian | 目标聚类后按源类中心做匈牙利匹配 |

## 结果（修正后）

| 视图/模型 | Clean-only | CORAL | Pseudo-label | KMeans-Hungarian |
| --- | ---: | ---: | ---: | ---: |
| D/LR | 0.140 | **0.210** | 0.209 | 0.113 |
| D/RF | **0.180** | 0.166 | 0.180 | 0.113 |
| C/LR | 0.392 | **0.398** | 0.054 | 0.218 |
| C/RF | **0.496** | 0.433 | 0.148 | 0.218 |

## 结论

1. CORAL 只在 D/LR 上明显提升（0.140→0.210），D/RF 与 C/RF 下降；
2. 伪标签在 C 视图崩溃（0.392→0.054、0.496→0.148），不可用；
3. KMeans-Hungarian 全部低于 Clean-only；
4. 没有任何无标签方法在四个视图/模型组合上稳定超过 Clean-only。

> 无标签适应不能作为有效攻击基线；残余更可能来自跨防御稳定的可观测特征，而不是缺少无监督适应。

## 审计记录：两个已定位问题

1. **BA 聚合口径不同**
   - 标签矩阵：每日 BA 再平均；
   - 原 Frozen-UDA：所有 flow 合并后算一个 BA；
   - 已统一为每日 BA 再平均。
2. **C 特征二次变换**
   - 原代码先把 `x` 转成 45 维 C，又在循环里调用一次 `views()`；
   - 已改为只转换一次。

## 四层 alignment audit

同一进程、同一 warm/target、同一 RF 实例，结果：

| 层 | 结果 |
| --- | --- |
| 数据 | warm=4000，target=18459，150 天；日期 2016-10-20 至 2017-04-12 |
| warm 类别 | `[0,24,1197,2646,0,34,0,99]` → **只有类别 1/2/3/5/7** |
| target 类别 | `[8307,1850,2924,3648,494,479,448,309]` → 全部 8 类 |
| 特征 | C shape `(4000,45)` / `(18459,45)`，float64，哈希 `5088b0f0…` / `48317689…` |
| 模型 | 同一 RF：64 树、random_state=7500 |
| 预测 | 分布 `[0,2277,2675,11932,0,476,0,1099]`；类别 0/4/6 从未被预测 |
| 评分 | **每日平均 0.4956；合并 flow 0.5986** |

结论：

- UDA 的 Clean-only **0.4956** 与 canonical 每日平均完全一致；
- 标签矩阵存储的 C/RF Frozen-clean **0.6091** 是异常值，需重跑矩阵；
- **warmup 只覆盖 4 类**，所以 Frozen-clean 无法识别 0/4/6，BA 上限被人为压低；
- 这也解释了伪标签为什么会在 C/LR 上崩溃。

## 伪标签崩溃诊断（C/LR）

初始预测类别分布：

`[3178, 2338, 8275, 253, 4415, 0, 0, 0]`

- 只预测 0–4 类；
- 类别 0/6/7 从未出现；
- 预测大量集中到类别 2/4；
- 初始 BA **0.0014**，远低于 8 类随机 0.125，但不是标签编码错误：源域 warmup 本身没有类别 0/4/6，模型没有这些输出。

自训练后：

| 轮次 | 预测分布 | BA |
| --- | --- | ---: |
| 0 | `[3178,2338,8275,253,4415,0,0,0]` | 0.0014 |
| 1 | `[2916,2418,10428,163,2525,3,6,0]` | 0.0016 |
| 2 | `[2912,2464,10431,56,2492,79,25,0]` | 0.021 |
| 3 | `[2910,2486,10401,29,2476,117,0,40]` | 0.047 |

伪标签进一步把预测集中到类别 2，确认是**类别覆盖缺失 + 自训练放大偏差**，不是简单的输出列错位。



修正后：

- C/RF：标签矩阵 Frozen-clean **0.609**，本实验 **0.496**，仍差 **11.3 pp**；
- D/RF：**0.221** vs **0.180**，差 **4.1 pp**；
- D/LR：**0.172** vs **0.140**，差 **3.2 pp**。

因此本表只作方法内相对比较；在消除剩余差异前，不启动特征消融。

剩余需核对：

- clean 训练集是否完全同一批 warmup；
- 目标 Blind 的 ID/类别/日期是否完全一致；
- C 特征列顺序、归一化、零填充处理；
- RF 参数、随机种子、`n_jobs` 与每日 BA 的类别集合。
