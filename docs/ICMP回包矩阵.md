# ICMP 回包矩阵：48% / 56 B 固定参数

## 协议

- 每个 Trigger 独立尝试触发 ICMP 回包；
- 返回率 **48%**，回包大小 **56 B**，延迟 **50 ms**；
- Full New5 的码本、State、预算、Blind、标签到达不变；
- 同一组 Blind、标签、State seed 与回包随机数；
- 主评价窗口为原始 32-event；
- Deakin10：50 日；UNSW8：P8-48（8 类 warmup、48 日）。

24 个配置 = 2 数据集 × 2 视图（C/D）× 3 模型 × 2 更新方式，每个 3 个配对 seed。
Deakin 仅补 MLP，UNSW 补 LR/RF/MLP。

## 判读

1. **D 视图收益稳定**：两个数据集、三个模型、累计/滑动都下降；UNSW D/LR 与 D/MLP 累计约 −0.10，D/RF 约 −0.064。
2. **Deakin C/MLP 有明确收益**：累计 −0.016、滑动 −0.094，三个 seed 同向。
3. **UNSW C 基本不动**：C/RF 累计 0.000，C/MLP −0.001，C/LR −0.010；无法复制 Deakin 的 C 收益。
4. **C 的收益依赖数据集**：不能把 Deakin 的 C/MLP 结果外推为“ICMP 回包解决 C 视图”。
5. **实现是合成回包**：48%/56 B 是冻结参数，不代表真实路由 ICMP 可达率或真实 56 B 回包行为。

## 结论

> 48% / 56 B 的 ICMP 回包在 D 视图上稳定有效，在 Deakin C/MLP 上有明显收益；但 UNSW C 几乎没有变化。ICMP 回包不是 C 视图的通用解法，收益依赖数据集的可操作统计。
