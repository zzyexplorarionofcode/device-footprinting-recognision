# P8-48 静态源域对照：基础扰动 / IID State / 码本刷新

48 观测日（2017-02-23 至 2017-04-13），warmup 覆盖全部 8 类；零部署后标签。

## 设计

| 组 | 训练模型 | 评估臂 |
| --- | --- | --- |
| A Clean-model | clean warm 训练一次 | Clean / Fixed-map / Fixed-IID / Full New5 |
| B Initial-model | initial defended warm（首套码本 + IID）训练一次 | Fixed-map / Fixed-IID / Full New5 |

同一组内**模型完全相同**，只换评估流量。

## 三个问题的回答

### 1. 基础扰动是否让完全不知防御的旧模型失效？

**是，但只在 D 视图。**

- Clean-model 从 Clean 到 Fixed-map：
  - LR 0.850 → 0.399（−45.1 pp）
  - RF 0.996 → 0.441（−55.5 pp）
- Fixed-map 与 Fixed-IID 接近，说明“有 trigger/weakener”本身已经让 clean 模型失效；
- C 视图几乎不变（0.861/0.912），说明基础扰动没有消除顺序无关统计。

### 2. IID State 是否进一步削弱已经认识初始防御的模型？

**只有边际作用，且方向不稳定。**

- Initial-model：
  - LR 0.767 → 0.763（−0.4 pp）
  - RF 0.956 → 0.940（−1.6 pp）

IID State 对“已经见过初始 defended 流量”的模型没有显著额外收益。  
它主要帮助的是 clean→defended 的分布失配，而不是在已适应初始防御后继续削弱。

### 3. 码本刷新是否在 IID State 之外继续提供收益？

**是，D 视图有明显增量。**

- Initial-model：
  - LR 0.763 → 0.666（−9.7 pp）
  - RF 0.940 → 0.896（−4.4 pp）

5 日码本刷新在 IID 之外仍有 4–10 pp 的 D 视图收益。  
但 C 视图完全不变，说明刷新只作用于序列/位置视图，不触及顺序无关长度统计。

## 结论

> 在 P8-48 完整类别闭集、零部署后标签下：
> 1. 基础扰动让 clean 模型在 D 视图上大幅失效（−45 到 −56 pp）；
> 2. IID State 对已认识初始防御的模型只有 0–2 pp 的边际作用；
> 3. 5 日码本刷新在 IID 之外再提供 4–10 pp 的 D 视图收益；
> 4. C 视图在所有防御臂上保持 0.86–0.98，动态序列扰动未能消除跨防御稳定的统计指纹。

## 限制

- 仅 UNSW8、seed 0、48 天；
- C 视图按定义不含 Trigger 长度区间，故对码本刷新天然不敏感；
- 不能把 48 天结果外推到 150 天；
- 这是零标签静态攻击，不含在线适应。
