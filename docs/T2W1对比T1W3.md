# T2_W1 与 T1_W3 等预算支线实验

## 冻结协议

单配对Seed=0的探索性回放；UNSW8为150观测日、Deakin10为50观测日。沿用Full New5、K=6、均匀逐流IID、每日评分后释放8标签，累计与14日滑动LR/RF参数不变。相同原始流、Blind、标签账本及共同T1_W3热身历史。D=64维，C=45维可观测顺序无关组合。没有重新搜索码本。

T指Trigger对数。T1_W3：两包Trigger283B/0.45s，三包Weakener347B/1.05s。T2_W1：四包Trigger566B/0.9s，一个Weakener64B/0.6s。均为五个新增事件，硬预算630B/1.5s。T2弱化dummy固定60B，最多剩4B用于真实包padding；原84/115B候选不再适用。两组实际成本见下，不宣称实际字节与时延严格相等。

第一对沿用原逐阶段随机码本，第二对由seed=300000+1000*repeat+stage独立生成，每对保持283B/0.45s及原5%零和jitter。四个位置在1..16内，第二对遇第一对冲突时选最近未用位置，距离相同选较小者；按锚点排序并携带对应码包。两对使用相同逐流jitter分位点，此规则预先固定，不以Blind选择。生成前的独立性不等于最终位置独立，消解冲突引入结构变化。

## 判读

原64维下，T2在UNSW8四种攻击上降低BA，在Deakin四种攻击上提高BA，未见跨数据集统一优势。UNSW8的C视图累计RF仍约0.965，说明更多Trigger未解决已测无序残余泄漏。Deakin的C结果与D不同，仍需按视图和模型报告。单Seed、已见开发数据不支持显著性或泛化结论。

此比较同时改变Trigger数量、位置覆盖、资源分账、Weakener数量和分布以及真实包padding额度，属于整体配置比较，不能归因为纯Trigger对数效应。当前不扩展参数搜索。

代码：scripts/two_trigger_pairs.py、scripts/two_pair_replay.py；入口：python -X utf8 -B -m scripts.state_count_ablation --family unsw8（或deakin10） --seed 0 --two-pairs。原始逐日结果：artifacts/es/two_pairs_{family}_s0.json。原核心14项测试通过；回放逐流断言5个dummy与硬预算，并核对两组每日标签使用数量、评分日期和Blind类别支持一致。
