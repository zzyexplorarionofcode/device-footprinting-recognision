# Weakener 第一阶段：残余特征审计

UNSW8 使用冻结的 150 个观测日，Deakin10 使用 50 个观测日。本轮固定使用已有回放的 seed 0。Clean 与 Full New5 使用相同原始流、warmup 样本、每日 8 个评分后到达的标签和 Blind 样本。各臂在自己的输入视图上训练 LR 与 RF，报告累计与 14 日滑动的日均 Post BA。两组 Clean C 使用原 32-event 窗口，Full New5 C 沿用防御后 32-event 窗口和已冻结的结果。

原 C 是 45 维的混合视图，包含下行和大于 256 B 事件的包长统计与事件数。拆分诊断对 Full New5 的输出单独计算以下视图。

| 视图 | 输入 |
|---|---|
| 真实上行包长 | 可见窗口内标记为真实的上行包，16 桶归一化长度直方图。使用渲染日志辨别真实包，属于 oracle 诊断 |
| 可见上行包长 | 所有可见上行事件的 16 桶归一化长度直方图，包含 dummy |
| 下行包长 | 可见下行事件的 16 桶归一化长度直方图 |
| 事件数 | 窗口内的可见上行与下行事件数 |
| 字节规模 | 窗口内的可见上行与下行字节总数 |

真实上行视图的识别率衡量现有防御输出还含有多少上行长度信号。可合法修改的包长区间、目标长度以及实际花费需要在后续 warmup 和渲染审计中测定。

对 warmup 中含上行包的流，以各数据集最长上行包长的第 75 百分位为阈值，同值纳入上组。单包 headroom 取最大帧长余量与单包 padding 上限的较小值，按原始 32-event 窗口内上行包求和。

| 数据 | 长包阈值 | 上组 / 其余流数 | 上行字节中位数 | 可 padding 上行字节中位数 | headroom 中位数 |
|---|---:|---:|---:|---:|---:|
| UNSW8 | 1514 B | 1706 / 2294 | 3735 / 1469 B | 2221 / 1469 B | 3380 / 2648 B |
| Deakin10 | 402 B | 1031 / 2969 | 2736 / 1070 B | 2736 / 1070 B | 1300 / 1300 B |

两套 warmup 都呈现上行字节规模增加，只有 UNSW8 的 headroom 中位数随之增加。以上数值是插入前窗口的物理上限估计，实际可见 padding 还受目标长度、逐流预算和防御后截断影响。

## 日均 Post BA

### Deakin10

| 输入 | 累计 LR | 滑动 LR | 累计 RF | 滑动 RF |

| Clean C | 0.4604 | 0.4667 | 0.5474 | 0.5034 |

| 可见上行包长 | 0.4517 | 0.4729 | 0.4838 | 0.5180 |
| 下行包长 | 0.1200 | 0.1206 | 0.1205 | 0.1205 |
| 事件数 | 0.1585 | 0.1798 | 0.2488 | 0.2730 |
| 字节规模 | 0.1954 | 0.1986 | 0.6874 | 0.6649 |

单用真实上行包长的累计 RF 在 UNSW8 达到 0.9016，在 Deakin10 达到 0.5279。UNSW8 单用下行包长达到 0.9178，Deakin10 单用字节规模达到 0.6874。各拆分视图单独训练，BA 无法相加或换算为对 C 的贡献。阶段二应以等实际真实包 padding 开销的配对回放检验可改变的部分。

复现命令为 `python -X utf8 -B -m scripts.state_count_ablation --family unsw8 --seed 0 --weakener-audit`，Deakin10 将参数替换为 `--family deakin10`。逐日记录位于 `artifacts/es/weakener_feature_audit_{family}_s0.json`。
