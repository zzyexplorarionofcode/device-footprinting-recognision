# 历史差异性感知的随机新码本

## 冻结协议

对 Full New5 与 Novelty New5 作配对比较。每 5 个观测日更新、K=6、逐流均匀 IID、T1_W3 与通信预算均固定。候选池大小固定 4，历史窗口固定最近 3 套部署码本；首段双方取相同第一候选。后续 Full 直接取池首个，Novelty 取最远候选，同分取最小池索引。第一候选严格复用原 Full New5 生成序列，额外三个候选的种子预先由重复和阶段编号确定。

距离按相同 code index 对齐。位置除以 16、包长除以 Trigger 总字节 283、gap 除以 Trigger 总延迟 0.45，各组件先取均方差，三组件等权再开平方。候选差异分数是到最近三套历史中最接近者的距离。此为参数差异代理，不保证产生相同大小的可观测分布变化。选择完全依赖已部署码本，不使用攻击者评分。

Full 的全期结果复用，补算相同历史模型在切换日原始流的前码本反事实 BA；Novelty 按相同协议完整回放。比较切换前历史训练模型在新码本和前码本下的配对评分。负值表示旧模型在切换后更差。该项是瞬时迁移诊断，主指标仍为全期日均 Post BA。

## 判读

Novelty 在两套数据都提高了预设参数距离，约为 Full 的 1.13 倍，但没有稳定降低累计攻击者的全期 Post BA。八种数据集与攻击更新组合均有逐重复方向变化。部分切换冲击变大，未对应一致长期收益，距离与冲击的相关方向也不稳定。本轮只否定该固定差异代理和四候选池规则的稳定增量，不能将其外推为所有可观测分布差异均无价值。保留 Full New5 与 Position5，当前不引入差异阈值学习或 PPO。
