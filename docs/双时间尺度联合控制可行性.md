# 双时间尺度预设控制：2×2 可行性检验

## 协议

复用 UNSW8 原 150 个观测日、原始流、Blind、热身、标签到达与实际通信开销。三次重复使用同一开发时间段。所有臂逐流独立抽样，用同一原始行的均匀随机数经各自的 State 分布变换。

A 为原 Full New5。B 与 A 同码本序列，快层每日轮转概率向量 (0.28, 0.22, 0.17, 0.14, 0.11, 0.08)，150 个观测日等权平均回到均匀。C 保持均匀 IID，慢层依次部署 5、10 日的码本，重复十轮。D 同时应用两项改动。C/D 复用 A/B 的前 20 套码本，A/B 部署 30 套。慢层同时改变更新时间和部署数量。快层改变的是同时关联位置、长度和 Gap 的 Mapping State 使用概率。所有规则事先固定，动作不读取攻击模型或 BA。

## 复现

沿用 Full New5 回放命令，加 --control-arm fast、slow 或 joint，输出 artifacts/es/two_timescale_{fast,slow,joint}_s{0,1,2}.json。A 使用原 new_codebook_period5_s{0,1,2}.json。日志中的 regime 继续按五观测日标记决策机会；实际码本持续时间由 control.codebook_durations 记录。

## 判读

快层仅使累计 LR 平均小幅下降，逐重复变号，滑动 LR 平均上升。慢层平均提高两种攻击的 Post BA。联合平均交互为负，但联合 BA 仍高于 Full New5，且交互方向跨重复变化。阶段一未建立稳定的增量收益，Full New5 保留为参照，阶段二和 PPO 尚不启动。该判断限于这两条预设规则和当前 UNSW8 开发窗口。
