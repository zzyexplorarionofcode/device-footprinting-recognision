# 双时间尺度防御：时间泛化审计与生成器评估隔离

## 冻结强基线

冻结三条随机新码本序列及逐流均匀六 Mapping 结果。随机生成器每 25 个观测日生成一个合法码本，始终使用相同的 T/W 数量、预算分区和可实现性校验。150 日累计 LR 平均 Post BA 为 0.7939，配对 Stationary IID 为 0.8256。滑动 LR 结果为 0.7568 对 0.7656。详见 [连续生成 Trigger 在线回放](连续生成Trigger在线回放.md)。

## 时间覆盖审计

UNSW8 数据提取清单的八台设备合计有 171 个符合当前流提取协议的 UTC 日期，覆盖 2016-09-30 至 2017-04-13。全部日期都出现在预处理数据。首轮使用 2016-09-30 至 2016-10-19 的 20 个日期热身，之后 150 个观测日至 2017-04-12 用于在线回放。唯一未进入该回放的日期 2017-04-13 含 39 条流，均属于类别 0。对当前八台设备和提取规则重新采样无法产生新的日期。单日单类无法支撑多类、跨段的在线复验。

已用现有逐日结果做描述性时间敏感性检查。把 150 个观测日按先后等分为三个 50 日区间，沿用原在线模型的历史状态。差值为双时间尺度策略减 Stationary IID。各区间的两臂使用同日同一批原始流、相同逐流 Mapping 和标签账本。三个区间是同一回放的分段读数，训练历史跨区间累积。这些结果不可作为独立时间泛化证据。

| 区间 | 累计 LR 逐序列 Δ | 累计 LR 平均 Δ | 滑动 LR 平均 Δ |
| --- | --- | ---: | ---: |
| 2016-10-20 至 2016-12-27 | −0.0278 / −0.0235 / −0.0169 | −0.0228 | −0.0160 |
| 2016-12-28 至 2017-02-19 | −0.0105 / −0.0189 / −0.0601 | −0.0298 | −0.0145 |
| 2017-02-20 至 2017-04-12 | −0.0559 / −0.0421 / −0.0297 | −0.0425 | +0.0042 |

累计 LR 的全期下降没有集中在一个 50 日区间。滑动 LR 的结果随区间改变方向。严格复验需要新取得、按时间独立的多类捕获。若使用不同设备或数据集，应单独报告为外部验证，并注明设备集合、码本及提取协议差异。

## 学习型生成器的训练、验证、测试隔离

1. **开发训练。** 把现有 UNSW8 数据整体视作已见开发数据。在开发数据内按 UTC 时间先切训练区间，再切时间晚于训练的验证区间。任何训练 episode 及其热身、Calibration、奖励评分样本不得跨越训练边界。在线标签按原协议到达；防御者的状态只能读取部署时可得的因果历史。模拟攻击者和训练奖励在训练区间内使用。测试 Blind 标签及评分不进入生成器输入或奖励。
2. **开发验证。** 只用随后冻结的验证区间选模型、奖励权重、超参数和 checkpoint。评价使用持续更新攻击者的日均 Post BA。保存候选定义、动作可行性规则、评估代码、模型 checkpoint 和随机种子。完成选择后冻结配置。旧数据已用于形成研究假设，内部验证承担开发选择用途。
3. **独立测试。** 使用从未进入动作设计、训练、验证或 checkpoint 选择的新时间段。正式 150 日比较需要同一协议下独立的 20 个观测日热身和 150 个观测日测试。热身只初始化攻击者和部署允许的历史状态，测试期间生成器按冻结规则行动。攻击者可使用截至当日已获准的标签，Blind 仅用于最终评分。评分后再调整生成器，调整版需要另一份未参与选择的测试数据。
4. **配对主比较。** 学习型生成器对比随机新码本生成器。两者共用合法动作空间、每 25 个观测日换码本的机会、相同 T/W 预算、逐流 Mapping 随机数、热身数据、标签规则和 Blind 流。冻结学习策略对测试生成器信息权限的定义。若部署可用信息仅包括日历与网关观测，生成器不得访问攻击者私有权重或模拟测试 BA。所有生成码本先通过合法性和可实现性校验，报告逐流成本。
5. **判读。** 主效应是学习型减随机生成器的 150 日日均累计 LR Post BA。报告各配对 seed 和独立测试窗口的差值，滑动 LR 单独列为稳健性结果。切换冲击和恢复耗时作为诊断。独立测试的日期清单、标签流索引和分配规则先登记，测试日志在冻结后统一评分。已有发现不构成对交互项的估计。

当前已完成时间覆盖与区间敏感性审计。独立时间复验尚缺新捕获，学习型生成器尚未训练。
