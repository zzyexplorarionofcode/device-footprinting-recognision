# 实验协议冻结：三类类别覆盖

> 冻结日期：2026-11-07。停止新的 Weakener / Hybrid 搜索；后续只按下列三类协议解释结果。

## 1. P5-150：已知五类，长期动态防御

| 项 | 定义 |
| --- | --- |
| 已知类别 | 1 / 2 / 3 / 5 / 7 |
| warmup | 首观测日之前，只含这 5 类 |
| 测试 | 150 观测日；只评估这 5 类 |
| 问题 | 长期动态防御能否阻碍攻击者持续识别已知设备 |
| 指标 | 5 类闭集 BA、每日 Post BA、T_first / T_sustained |

要求：

- 训练与评估都不出现 0/4/6；
- 若评估中出现未知类，按 open-set 单列，不能混入闭集 BA。

## 2. P8-48：已知全部八类，完整类别识别

| 项 | 定义 |
| --- | --- |
| 已知类别 | 0–7 |
| warmup | 2017-02-23 之前；8 类均有样本 |
| 测试 | 2017-02-23 至 2017-04-13，48 个观测日 |
| 问题 | Full New5 能否降低完整 8 类识别率 |
| 指标 | 8 类闭集 BA、每日 Post BA |

warmup 类别分布：

`[596, 514, 504, 503, 381, 500, 502, 500]`

限制：

- 只有 48 天，不能与 150 天绝对值直接比较；
- 类别 4 的 warmup 只有 381 条，需在报告中注明；
- 这是目前 UNSW 上唯一合法的“初始认识全部八类”协议。

## 3. P8-open / 增量（可选，暂不启动）

| 项 | 定义 |
| --- | --- |
| 初始已知 | 早期出现的类别（1/2/3/5/7） |
| 后续出现 | 0/4/6 |
| 问题 | 新设备类别随时间出现时，攻击者如何逐渐识别 |
| 指标 | known-class BA、unknown detection、首次识别延迟 |

这不是 8 类闭集，不能与 P8-48 混表。

## 4. 三个必须分开的因素

| 因素 | 表现 | 对应实验 |
| --- | --- | --- |
| 防御导致的分布偏移 | clean→defended BA 变化 | Frozen-clean / Frozen-initial |
| 攻击者获得新标签的能力 | 1/2/4/8 标签/天 | 标签矩阵 |
| 攻击者起初是否认识所有类别 | warmup 类别覆盖 | P5-150 / P8-48 |

任何结论必须同时说明这三项，否则不可解释。

> “初始认识全部 8 类的攻击者仍能识别……”

## 6. P8-48 当前结果

| 视图/模型 | Frozen-clean | Frozen-initial |
| --- | ---: | ---: |
| D/LR | 0.416 | 0.666 |
| D/RF | 0.419 | 0.896 |
| C/LR | **0.861** | 0.875 |

解释：

- 8 类 warmup 后，C 视图的 Frozen-clean 残余很高；
- 之前 C/RF 0.395 是缺类造成的，不是 C 视图没有残余；
- 但只有 48 天，不能外推为 150 天长期结论。

## 7. 冻结决定

1. 不再启动 Weakener / Hybrid 参数搜索；
2. P5-150 与 P8-48 分开报告；
3. 历史 150 日 8 类结果全部重新标注为“5 类 warmup + 8 类 target”；
4. 下一步若继续，只做协议内的机制拆解，不做新防御搜索。
