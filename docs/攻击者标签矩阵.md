# 攻击者标签矩阵：Frozen / Label-scarce / Adaptive

> **历史协议，已重新标注（2026-11-07）：**150 日 warmup 实际只覆盖 5 类（1/2/3/5/7），target 含 8 类。本表只能说明“5 类 warmup + 8 类 target”的历史在线回放，不能证明“攻击者初始认识全部 8 类”。P8-48 见 `实验协议冻结_三类覆盖.md`。

固定 Full New5 防御流（5 观测日刷新码本、逐流均匀 IID State、T1_W3），UNSW8 150 观测日，同一 Blind、同一 D/C 特征。

## 协议

- 初始训练：20 观测日热身，4000 条带标签 flow；**实际类别覆盖为 1/2/3/5/7**。
- **Frozen-clean**：只用 clean 热身数据训练，之后冻结。
- **Frozen-initial**：用初始 defended 热身数据训练（第一套码本），之后冻结。
- **Label-k**：初始 defended 热身 + 每天只取前 k 条新标签，累计训练。
- **Adaptive-8**：初始 defended 热身 + 每天 8 条新标签，累计训练（与 Label-8 相同）。
- 当天先评分 Blind，之后才释放当天标签；无未来标签。
- D：原 64 维长度/Gap；C：顺序无关长度统计（45 维）。

## 平均 Post BA

| 攻击者 | D/LR | D/RF | C/LR | C/RF |
| --- | ---: | ---: | ---: | ---: |
| Frozen-clean | 0.172 | 0.221 | 0.482 | 0.609 |
| Frozen-initial | 0.575 | 0.609 | 0.483 | 0.578 |
| Label-1/day | 0.655 | 0.712 | 0.815 | 0.855 |
| Label-2/day | 0.692 | 0.755 | 0.897 | 0.927 |
| Label-4/day | 0.745 | 0.833 | 0.918 | 0.943 |
| Label-8/day | 0.772 | 0.891 | 0.939 | 0.958 |
| Adaptive-8/day | 0.772 | 0.891 | 0.939 | 0.958 |

## 解释

1. **Frozen-clean 很低不是防御强**：clean 与 defended 特征分布不匹配，是 domain shift；不是 rotation 单独造成的。
2. **Frozen-initial 是更公平的零适应基线**：初始 defended 训练后冻结，D 0.575/0.609，C 0.483/0.578。动态防御确实让旧分类器退化，但没有完全失效。
3. **标签是主导因素**：每天 1 条标签就把 C 视图从 0.48/0.58 推到 0.815/0.855；D 视图推到 0.655/0.712。
4. **低标签回报很高**：1→2→4→8 的边际收益递减，但 1 条/天已经恢复大部分。
5. **C 视图在低标签下更强**：C 的顺序无关长度统计更容易用少量标签恢复，说明残余主要在长度边际。
6. **Adaptive-8 与 Label-8 相同**：当前 8/天就是强标签上界，不是额外机制。

## 结论

- 当前 Full New5 对 **零标签但初始 defended 知识充足** 的攻击者：D 0.58–0.61，C 0.48–0.58；旧分类器明显退化但仍有信息。
- 对 **每天 1 条标签** 的攻击者：C 0.82–0.86，D 0.66–0.71；标签成本极低即可恢复大量性能。
- 对 **每天 8 条标签** 的攻击者：D 0.77–0.89，C 0.94–0.96；与现有在线基线一致。

因此，防御的主要压力不是“零标签旧模型”，而是“极低标签率持续适应”；后续应重点报告 1/2/4 标签/天的曲线，而不是只报 8/天。

## 复现

```powershell
python -X utf8 -B -m scripts.attacker_matrix `
  --dataset data/processed/unsw_main8_v1/flows_unsw_8class.npz `
  --config configs/methods/fade_unsw8_pos_v2.json `
  --pilot artifacts/es/online_nonstationary_s0.json `
  --baseline artifacts/es/new_codebook_period5_s0.json `
  --output-log artifacts/es/attacker_matrix_lr.json `
  --models lr --views D,C --rates 1,2,4,8
```

RF 将 `--models lr` 改为 `--models rf`，输出 `attacker_matrix_rf.json`。
