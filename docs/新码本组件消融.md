# 五日码本更新的单组件消融

固定 5 个观测日的更新间隔和逐流 IID Mapping。每次重复以该 Full New5 序列的第一套随机新码本作固定基准。单组件臂从同一序列复制该组件，其余组件保持首套码本参数。全体共享原始流、Blind、标签账本、热身和实际成本。每个混合配置重新验证位置唯一性、两包字节和间隔预算与 jitter 可行性。逐流成本与原预算配置配对。已验证三个冻结组件的逐码本字段及所有条件前 5 日逐日结果完全一致。Full New5 复用已有结果。

负差表示攻击 BA 较低。Full New5 对 Position5 的差值衡量在已更新位置时同时更新长度和 gap 的联合增量，包含组件交互。当前没有位置加长度、位置加 gap 两个中间臂，无法分别归因。三个重复共用同一 UNSW8 开发时段。

复现沿用 5 日更新命令，加 --component fixed、position、length 或 gap，输出 artifacts/es/new_codebook_component_{fixed,position,length,gap}_s{0,1,2}.json。

Position5 保留了 Full New5 相对固定码本降幅的约 94%（累计 LR）和 96%（滑动 LR）。在三个重复和三个 50 日块中，单独更新位置都比固定码本低。Full New5 对 Position5 的额外下降较小，滑动 LR 的方向跨重复变化。该结果支持在当前 UNSW8 开发条件下把 Position5 作为简化生成器；正式等效性和外部泛化尚未验证。
