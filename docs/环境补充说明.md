# 环境补充说明

本包以 Python 3.11 为基准。打包时的本机环境为 NumPy 1.26.4、SciPy 1.17.1、scikit-learn 1.9.1、PyTorch 2.5.1+cu121。CPU 可以执行核心算法和首次检查；GPU 用于加速 LSTM 与 iPET 训练。

## Glimpse 的可选依赖

`baselines/glimpse/requirements.txt` 保留原仓库依赖：TensorFlow 2.15.0、tf-keras 2.15.0、TensorFlow Probability 0.23.0、TF-Agents 0.19.0。可以先在单独的 Python 3.11 环境中使用该依赖文件运行 Glimpse demo。

TF-Agents 0.19 声明固定 `typing-extensions==4.5.0`，与 PyTorch 2.5 所需的较新版本冲突；因此把两个依赖文件直接交给 pip 一次解析，可能失败。本机现有环境使用 typing-extensions 4.16.0，原仓库已记录两个框架的实际运行验证，但仍有该项声明冲突。本包没有重新创建或修改 Python 环境。

完整统一基线运行需要两个框架在同一环境中可导入。环境尚未准备好时，先关闭基线配置中的 Glimpse 条目，学习 FADE 和其他基线。不要为满足旧依赖声明直接降低整个已有环境的 typing-extensions。

原生 Windows 的本机 TensorFlow 2.15 使用 CPU；PyTorch 可使用 CUDA。两者的设备选择相互独立。

## 检查命令

```powershell
python -B scripts/run_checks.py
python -B baselines/glimpse/self_test.py --core-only
python -B baselines/ipet/run_self_test.py
```

第一项执行随包测试并限制 PyTorch 的 CPU 线程；第二项仅验证 Glimpse 仿真核心；第三项包含 iPET 合成数据训练，运行时间更长。完整 Glimpse 自测还会训练 DDPG；原仓库记录过 Windows 上极小浮点差造成的严格精度断言失败，因此这里没有把完整 DDPG 自测列作首次检查。
