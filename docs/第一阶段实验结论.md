# 第一阶段实验结论：位置/长度/间隔贪心搜索与消融归因

本文件汇总第一阶段的防御效果与机制归因。所有数字来自 `artifacts/es/` 下的 JSON；完整评估定义见 [评估协议](评估协议.md)。

## 1. 协议

- 等成本：每流 +630 B / +5 events（2 trigger + 3 weakener）；32 事件窗口。
- 攻击者：LR / RF / MLP；clean（干净训练→防御测试）与 retrained（防御 old→next）。
- 搜索：按日期分组 3 折，目标 `max(BA_clean, BA_retrained)`，搜索目标使用 LR。
- 最终评估：capture-disjoint held-out A；B 只有 1 天，仅参考。

## 11. 总体结论

1. 等成本下 position 是主要可调维度；gap 次之；length 基本无效。
2. 效果是攻击者相关、数据集相关的：clean 基本 null；retrained 下 UNSW18 最强，CIC RF 几乎无效。
3. 位置效应集中在少数类（class5、class0、class6），类间有干扰，不能线性外推。
4. 防御作用于顺序敏感特征（mask/direction/sequence），不改变真实包长度/间隔的边际分布。
5. 长度直方图侧信道来自真实包，跨数据集 0.37~0.98，时间上稳定；位置搜索无法关闭它。
6. “防御有效”只能限定为：在评估的等成本配置、攻击者和数据集上，位置搜索造成有限、异质的 BA 下降。

## 12. 限制

- Deakin 尚未做位置/长度/间隔搜索，只有直方图分解。
- Mon 搜索仅 2 折、1 折改善，base 接近随机。
- length 搜索只在 UNSW 做过。
- 搜索目标只使用 LR；RF/MLP 为事后评估。
- held-out A 已被反复查看，B 只有 1 天；不是盲测。
- 部分 held-out 组合只有 LR。
