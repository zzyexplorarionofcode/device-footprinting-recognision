# 第一阶段简报（v2，固定 RNG）

## 一句话

在等成本约束下，**位置搜索对 retrained 攻击者有小到中等效果，对 clean 攻击者基本无效；gap 的 v2 效果很弱；Length 搜索（dummy code 长度）无效；FADE 的 weakener padding 会改变约 4% 真实事件，但位置搜索本身不改变长度边际，因此关不掉顺序无关的长度直方图侧信道。**

## 表 3b 机制分解（LR，正 = 防御降低 BA）

| dataset | representation | displacement | dummy_mixing | total |
| --- | ---: | ---: | ---: | ---: |
| UNSW | 0.015 | 0.004 | 0.026 | 0.046 |
| CIC | 0.036 | 0.012 | 0.075 | 0.123 |
| UNSW2018 | 0.058 | −0.005 | 0.086 | 0.140 |
| Deakin60 | 0.014 | 0.000 | 0.179 | 0.192 |

`CD_complete`（全部真实包）→ `CD_visible`（窗口内真实包）→ `CD_merged`（加 dummy）。**主因始终是 dummy_mixing，真实包位移很小。**

representation 非零的原因是真实包 padding，不是构造错位：~99% 流至少一个真实包被改长度，但只有 ~4% 事件变化，平均 +41 B/流；padding_prob=0 时 8000/8000 流 hist 完全一致。链式分解顺序固定为 `CC → CD_complete → CD_visible → CD_merged`，三个差值是路径依赖的，不能交换顺序或当作独立因果效应。

## 归因

- Position ablation（UNSW）：Δ LR 0.032、RF 0.119、MLP 0.047；不是所有模型一致。
- LOCO：class5 对 RF 贡献 +0.107；class0 对 LR/MLP 为负，说明类间干扰。
- 视角（UNSW retrained）：combined +0.075、gap +0.051、length −0.015、sequence −0.057；length_hist/gap_hist 精确为 0。

## RNG 修复

- 逐流 RNG 改为内容指纹（前 20 事件，不含标签/批内下标）。
- chunk / order / parallel / 重复内容测试通过。
- 旧 chunked 数字作废；v2 结果见 `artifacts/es/v2_*.json`。

## 限制

- FADE 不是“只插 dummy、不改真实包”：它同时做真实包 padding、dummy 插入、位置选择、32 窗口截断；**Length 搜索（改 dummy code 长度）与 Padding（改真实上行包长度）是两个变量，不能混写**。
- 搜索目标只用 LR；held-out A 已复用、不是盲测；Deakin 没有做位置搜索；Mon 接近随机。
- CIC 的 32 窗口会挤出大量真实包，这是协议本身的一部分。
