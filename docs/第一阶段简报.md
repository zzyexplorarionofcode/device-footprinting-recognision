# 第一阶段简报：位置/长度/间隔贪心搜索与消融归因

## 结论（一页版）

1. 等成本下，**position 是主要可调维度**；gap 次之；length 基本无效。
2. 效果**只对 retrained 攻击者稳定**；clean 攻击者基本 null。
3. 效果**攻击者相关、数据集相关**：UNSW18 最强，UNSW 中等，CIC 的 RF 几乎无效。
4. 防御作用于顺序敏感特征（mask/direction/sequence），**不改变真实包长度的边际分布**。
5. 旧表中 clean→defended 的大幅下降，主要来自 **merged 直方图里 dummy 的分布偏移**；只看真实包，C→D 损失小得多。
6. 因此第一阶段能支持的是：**等成本位置搜索造成有限、异质的 BA 下降**；不能支持“消除长度侧信道”或“worst-case over all attackers”。

## 四个问题的处理

1. **搜索目标**：论文写 “worst-case BA across clean-trained and retrained **LR** attackers”，不写 “worst-case attacker”。
2. **Held-out**：A 只能叫 capture-disjoint held-out evaluation，且已复用；B 只有 1 天；frozen 三折是同一日期池的重划分，不是盲测。
3. **数字定义**：统一重算已给 `run_id`（dataset_version / split_id / sample_protocol / binning / classifier / regime）；real-only 与 merged 分开；Deakin 60 与 119 分开。
4. **窗口与预算**：
   - 32 窗口 = 插入后取前 32 个事件，真实包会被挤出；不是 37。
   - 630 B = L2 帧长/特征层字节，不含前导码/FCS/IFG；1.5 s = 新增时延预算，不是整条流时长。
   - weakener 347 B / 1.05 s / 3 个 + trigger 283 B / 0.45 s / 2 个。
