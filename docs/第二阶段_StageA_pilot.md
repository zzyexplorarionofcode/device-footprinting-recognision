# Stage A pilot：Trigger on/off × Weakener 剂量

## 1. 目的与矩阵

- T = trigger pair 是否存在：0 或 1 对（0/2 个事件）；
- W = weakener dummy 事件数：0–5（受预算与长度上限约束）；
- 等成本 cap：630 B / 1.5 s；
- 位置固定为各数据集 v2 position candidate，不重新搜索；
- 数据集：UNSW-IoTraffic、CIC-9；特征：标准 64-d combined；LR/RF/MLP；
- 训练/测试：同一 capture-disjoint split，8k/8k。

预算分账：

- T=1：trigger 283 B / 0.45 s / 2 events；weakener 347 B / 1.05 s / W；
- T=0：trigger 关闭；weakener 630 B / 1.5 s / W（把 trigger 预算重分配给 padding/dummy）。

## 4. 四个发现

1. **Trigger on/off 是主效应，而且跨数据集稳定。**
   - UNSW：T0 retrained 0.97–1.00 → T1 0.15–0.45；
   - CIC：T0 0.70–0.87 → T1 0.03–0.25；
   - 没有 trigger 时，仅靠 padding/weakener，自适应攻击者基本恢复；有 trigger 时，retrained 仍接近 chance。

2. **Weakener 剂量没有单调收益。**
   - 在 T1 内，W 从 0 增到 3，retrained BA 反而略升（UNSW LR 0.226→0.261；CIC 0.090→0.138）；
   - 更多 weakener 主要降低 clean→defended 的 BA（zero-shot 更强），但不阻止 retraining 恢复；
   - 在 T0 内，W 对 retrained 几乎无影响（UNSW 0.96–0.99；CIC 0.70–0.87）。

3. **等成本下，W 增加是用 dummy 替换真实包 padding。**
   - UNSW T0：padding 606 B→121 B，dummy 0→508 B；
   - CIC T0：padding 612 B→122 B，dummy 0→508 B；
   - 所以 W 的“剂量效应”同时包含“dummy 增加”和“padding 减少”，不能单独解释为 dummy 数量。

4. **长度直方图模式对 composition 不敏感。**
   - 16-bin hist 的 retrained BA 在 UNSW 为 0.94–0.99、CIC 为 0.70–0.87 的 T0 段；T1 段也接近饱和/无单调变化；
   - 说明 trigger/weakener 主要改变 aligned 表示，不改变顺序无关的长度边际；这与第一阶段结论一致。

- Trigger 效应在 W=0 最大，加入 weakener 后略减弱，但没有消失；
- 方向是“trigger 是主防线，weakener 是辅助/分布偏移层”，不是对称的两种原语。

## 6. 不能直接下的结论

- **不能**说“trigger 数量本身导致防御”，因为 T0 同时改变了预算分配、trigger code 存在性、映射旋转；
- **不能**说“weakener 越多越好”，W 增加同时减少 padding；
- **不能**说“trigger 与 weakener 有稳定协同”，因为当前 T0/T1 的 padding 字节不匹配，交互项被预算重分配污染。

## 7. 下一步控制（Stage A.1）

在扩大矩阵前，必须先做三个控制：

1. **Placebo trigger**：T=1 但 trigger 长度/位置 class-independent（无类特定 code），用于分离“额外事件/预算”与“类特定 code + 映射旋转”。
2. **Padding-matched T0**：T=0 但只给 weakener 347 B（不用满 630 B），或显式固定 padding 字节，使 T0/T1 的真实包 padding 接近。
3. **Fixed 5-event composition**：固定总 dummy=5，只改变 trigger/weakener 组成（如 2+3、0+5、4+1），分离“事件数”与“组成”。

只有这些控制显示 trigger 的类特定 code/rotation 仍是主因，才进入 Stage B 的多 trigger pair 剂量实验。

## 8. 结论（评估）

- Stage A 值得做，且已经给出明确方向：**trigger 层是自适应攻击者的主要障碍；weakener 剂量不是单调增益。**
- 当前结果足以支持“协同消融”的 pilot，但不足以支持因果性的“最佳配比”。
- 建议先做 Stage A.1 三个控制（约 0.5–1 天代码 + 2–4 小时计算），再决定是否做 Stage B 的 0/1/2 pair 剂量。
