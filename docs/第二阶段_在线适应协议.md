# 在线适应协议：BA_t(n)、N_τ、T_recovery 与 Mapping-aware attacker

## 1. 现有 pilot 是否泄漏？

`rotation_timeseries.py`：

- 对 block t，训练只用 block 0..t-1 的 defended 数据；
- block t 只用于测试；
- 没有把当前 block 标签用于训练或选择。

因此**没有当前 block 的测试泄漏**。但它也缺少：

- 显式的 n 个当前标签预算；
- 在线 probe/fine-tune；
- mapping-aware attacker；
- N_τ、T_recovery。

## 2. 在线 block 协议

每个映射切换后：

1. **切换**：防御者进入新 mapping 状态；
2. **标签积累**：攻击者获得当前 block 前 n 条流的标签；
3. **更新**：用这 n 条做 permutation / probe / fine-tune；
4. **盲测**：在剩余未见流量上评估 BA，标签不提供；
5. **持续**：重复，记录 BA_t(n)。

统一约束：

- 同一 block 内，所有攻击者使用**相同的前 n 条标签**；
- 盲测集是同一批剩余流量；
- 不同 n 之间，标签是前缀关系（n 增大只增加标签，不换样本）；
- 测试标签永不可见；
- 同一 flow 顺序、同一训练数据可用范围。

## 3. 指标

### 3.1 BA_t(n)

映射切换后第 t 个阶段、给 n 个当前标签时的盲测 BA。

### 3.2 N_τ

\[
N_\tau = \min\{n: BA(n) \ge \tau\}
\]

含义：达到阈值所需的当前映射标签数。若到最大 n 仍未达到，标记右删失。

阈值：

- 绝对：0.5、0.8；
- 相对：clean BA 的 50%、80%。

### 3.3 T 指标

- **T_first**：首次 BA_t≥τ；
- **T_sustained**：连续 2 个 block ≥τ；
- **T_recovery**：每次 mapping 切换后，从切换点到重新达到 τ 的 block 数/flow 数；
- 未达到 → 右删失，不记无穷大。

### 3.4 J(H)

\[
J(H,n)=\frac{1}{H}\sum_{t=1}^{H} BA_t(n)
\]

H 为观察期 block 数；对多相位/多 seed 给 bootstrap CI。

## 4. Mapping-aware attacker

### 4.1 Mapping-unaware

把所有历史 mapping 状态的数据混合训练一个模型。

### 4.2 Mapping-aware, schedule-known

- 按历史 mapping 状态分组；
- 每个状态训练一个专家；
- 部署时知道当前状态（或周期/相位），直接选对应专家；
- 这是最强上界。

### 4.3 Mapping-aware, state-inferred

- 同样训练每个状态的专家；
- 用 n 个当前标签给每个专家打分；
- 选在标签上表现最好的专家；
- 在剩余流量上盲测；
- 也可训练一个“状态分类器”，用流量特征推断状态。

### 4.4 公平性

三种攻击者必须：

- 使用相同历史数据量；
- 使用相同 n 个当前标签（或 0）；
- 在相同盲测集上评估；
- 相同模型容量/训练预算。

否则比较的是数据量/容量，不是 mapping-aware 能力。

## 5. Per-flow 的特殊处理

Per-flow mapping 没有 block 级状态，需要：

- 每条 flow 的 mapping 状态作为隐变量；
- mapping-aware 攻击者可以按 flow 推断状态，或按状态分组训练；
- 评估时只能使用当前 flow 的 n 个标签（如果 n 以 flow 为单位）；
- 或者把 per-flow 视为“每个 flow 一个状态”，此时 state inference 本身就是难点。

## 6. 实验矩阵

| 维度 | 取值 |
| --- | --- |
| policy | Fixed / Periodic(P=1,2,5) / Per-flow |
| training | cumulative / sliding W=2,5,10 |
| adaptation | permutation / probe / fine-tune |
| n | 0, 16, 64, 256, 1024 |
| attacker | unaware / schedule-known / state-inferred |
| threshold | absolute 0.5/0.8；relative 50%/80% clean |
| metrics | BA_t(n), N_τ, T_first, T_sustained, T_recovery, J(H,n) |
| uncertainty | 多相位/多 seed；block bootstrap |
| dataset | UNSW（多 block）；CIC（block 2 天） |

## 7. 当前校准结果对 n 的提示

- permutation 只能到 0.44–0.51；
- probe/fine-tune 在 n=256–1024 到 0.58–0.94；
- 因此 N_τ 很可能在数百级；
- 在线实验必须把 n=256/1024 纳入，否则会低估攻击者。

## 8. 实现顺序

1. 在线 block 切分与统一 n 前缀；
2. permutation / probe / fine-tune 三种更新；
3. mapping-aware 专家与状态选择；
4. N_τ/T_recovery/J(H,n) 计算；
5. 多相位/多 seed；
6. 再扩到 CIC、RF/MLP。
