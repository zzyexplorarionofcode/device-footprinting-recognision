# 在线适应核心矩阵：定义冻结版

## 1. 实验单位

- 数据集：先 UNSW / LR；
- 10 天/block，16 个测试 block；
- 每个 block：
  - 前 50%：calibration pool（可含无标签/有标签）；
  - 后 50%：blind，仅评估，不参与训练/选择；
- 所有 attacker 使用相同 flow 顺序、相同 block、相同 blind。

## 2. Policy

| policy | mapping |
| --- | --- |
| Fixed | 所有 block 同一 mapping |
| Periodic | 每 2 block 轮换，phase 可调 |
| Per-flow | 每条 flow 独立随机 mapping |

## 3. Attacker 矩阵

| policy | Known-mapping | Adaptive-Probe | Adaptive-Finetune |
| --- | --- | --- | --- |
| Fixed | 必做 | 必做 | 必做 |
| Periodic | 必做 | 必做 | 必做 |
| Per-flow | 必做 | 必做 | 必做 |

### 3.1 Known-mapping

- 知道当前 mapping（block 或 flow 级）；
- 使用 **oracle trigger identity**（真实 code + trace position）做 canonicalization；
- 在历史 canonical 数据上累计训练；
- 当前 blind 上评估。

用途：逆变换本身的上界，不含 detector 误差。

### 3.2 Adaptive-Probe

- 不知道 mapping；
- 从当前 block 的**无标签流量**推断 state/mapping：
  - 位置似然；
  - joint code/position detector；
- 用推断 mapping 做 canonicalization；
- 用 n 条当前标签训练 probe；
- 在 blind 上评估。

用途：现实攻击者的快速适应能力。

### 3.3 Adaptive-Finetune

- 与 Adaptive-Probe 相同的 state 推断/canonicalization；
- 不从头训练 probe，而是在历史累计模型上 fine-tune；
- n 条当前标签，calibration 权重 = len(history)/n；
- blind 评估。

用途：长期存储 + 快速适应的攻击者。

## 4. 标签预算

n = 0, 64, 256, 1024。

- 从 calibration pool 内**按类分层随机**抽取；
- 所有 attacker 使用同一 n、同一抽样；
- n=0 时只允许无标签 state 推断；
- blind 固定，不随 n 改变。

## 5. 指标

### 5.1 BA_t

每个 block 的 blind balanced accuracy。

### 5.2 J(H,n)

\[
J(H,n)=\frac{1}{H}\sum_{t=1}^{H}BA_t(n)
\]

### 5.3 N_τ

\[
N_\tau=\min\{n:BA(n)\ge\tau\}
\]

- 绝对阈值：0.5、0.8；
- 相对阈值：clean BA 的 50%/80%；
- 未达到 → 右删失。

### 5.4 T 指标

- `T_first`：首次达到 τ；
- `T_sustained`：连续 2 block 达到 τ；
- `T_recovery`：每次 mapping 切换后重新达到 τ 的 block 数；
- 未达到 → 右删失。

### 5.5 在线成本

- state inference ms/flow；
- canonicalization ms/flow；
- probe/finetune 训练时间；
- 每 block 总 CPU 时间。

## 6. 配对与重复

- 每个 phase/seed：
  - 三种 policy、三种 attacker 使用同一划分和 blind；
  - 逐组计算 J、N_τ、T_recovery；
- 多 phase（0,1,2...）× 多 seed（0,1,2...）；
- 报告跨组均值、范围、paired difference/CI；
- 不只把所有 flow 合并算一个总数。

## 7. 第一阶段范围

先 UNSW / LR 完成 3×3 矩阵，确认：

- known 与 adaptive 的差距；
- probe vs finetune 的差异；
- Fixed/Periodic/Per-flow 的恢复时间与成本；
- N_τ 是否可估。

之后再扩：

- UNSW / RF, MLP；
- CIC / LR, RF, MLP。
