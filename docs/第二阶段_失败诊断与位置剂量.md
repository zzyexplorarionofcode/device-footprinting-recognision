# 失败诊断与位置剂量：Position mapping rotation 是核心

## 1. 失败诊断协议

对 A/B/C/D 四臂：

- 用训练集训练攻击者；
- 在**训练集内部**切 80/20 validation（按类分层），validation 与 test 都使用 next mapping；
- 在 validation 上学习 `pred→true` 的 Hungarian 置换；
- 把该置换应用到 **test** 预测，计算 permutation-aligned BA；
- test 标签从不参与置换搜索。

A/B/C/D 与 Position placebo 相同：W=3、630 B、同一批 8k 流、同一位置池。

## 2. 分类器失败结果

### CIC（retrained；unaligned / aligned）

| arm | LR | RF | MLP |
| --- | --- | --- | --- |
| A placebo_code | 0.159 / **0.498** | 0.064 / **0.673** | 0.212 / 0.495 |
| B placebo_position | 0.661 / 0.661 | 0.822 / 0.816 | 0.774 / 0.772 |
| C T0_matched | 0.722 / 0.722 | 0.851 / 0.848 | 0.806 / 0.801 |
| D real | 0.152 / **0.504** | 0.075 / **0.758** | 0.199 / 0.501 |

### UNSW（retrained；unaligned / aligned）

| arm | LR | RF | MLP |
| --- | --- | --- | --- |
| A placebo_code | 0.289 / **0.498** | 0.437 / **0.567** | 0.370 / 0.486 |
| B placebo_position | 0.907 / 0.907 | 0.999 / 0.999 | 0.954 / 0.954 |
| C T0_matched | 0.978 / 0.978 | 0.999 / 0.999 | 0.978 / 0.978 |
| D real | 0.269 / **0.539** | 0.349 / **0.612** | 0.338 / 0.517 |

判读：

1. **A/D 的低 unaligned BA 主要是系统性标签置换**：CIC RF 0.064→0.673、0.075→0.758；UNSW RF 0.437→0.567、0.349→0.612。
2. **B/C 的置换是 identity**：没有标签错配，B/C 的差异不是评估流水线问题。
3. **对齐后 A/D 仍低于 B/C**：CIC RF 0.673/0.758 vs 0.816/0.848；UNSW RF 0.567/0.612 vs 0.999/0.999。说明除了置换，还有真实的表示破坏/信息损失。

### 错分结构

CIC（B/C）：

- 主要错误是 **class 0 ↔ class 1**（Echo Dot 1/2）：B RF 532/509，C RF 535/533；
- 其次是 class 2/3、class 8；这些是已知的长度分布重叠，不是标签错配；
- B RF 0.830 vs C 0.856 的 2–3 点差异可以用这些类的误差解释，**不是 pipeline 标签对齐 bug**。

CIC（A/D）：

- 出现大量 `1→3`、`3→1`、`0→2` 等系统性错分；
- validation 学到的置换正是这些块的重新映射；
- 说明 next mapping 把 code/position 索引整体旋转，攻击者输出的是旧索引。

## 3. 关键修正：静态类位置不够，必须 rotation

新增“无 rotation”对照：α=1、code 全类相同、位置为类特定固定 pair（override 直接用 `pool[label]`，不经过 mapping）：

| dataset | 静态类位置（no rotation） | 类位置 + rotation | 随机位置（B） | T0（C） |
| --- | --- | --- | --- | --- |
| UNSW | **0.992 / 0.997 / 0.992** | 0.263 / 0.405 / 0.376 | 0.933 / 0.999 / 0.976 | 0.985 / 0.999 / 0.991 |
| CIC | **0.960 / 0.993 / 0.982** | 0.138 / 0.057 / 0.210 | 0.656 / 0.830 / 0.773 | 0.723 / 0.856 / 0.805 |

结论：

- **静态类位置是可学习的，几乎没有防御效果**；
- **同一个位置策略，只要经过 mapping rotation，就产生 0.6–0.9 的 BA 下降**；
- 因此 active mechanism 是 **position mapping rotation**，不是“类相关位置”本身。

这修正了上一份 Position placebo 的表述：

> 不是 “class-specific placement” 单独起作用，而是 “class-specific placement **under mapping rotation**”。

## 4. Position-only 可预测性

用 trigger pair 的 one-hot 位置训练一个 LR，仅用位置预测类别（retrained test）：

| α | CIC position-only BA | UNSW position-only BA |
| ---: | ---: | ---: |
| 0.00 | 0.114 | 0.129 |
| 0.25 | 0.083 | 0.099 |
| 0.50 | 0.052 | 0.058 |
| 0.75 | 0.029 | 0.037 |
| 1.00 | **0.000** | **0.000** |

无 rotation 的 α=1：position-only BA = **1.000**（UNSW/CIC），retrained BA 0.96–0.99。

这直接说明：

- 没有 rotation 时，位置是完美的类别标签；
- 有 rotation 时，位置与测试类别完全脱钩，攻击者无法从位置恢复标签；
- 防御来自“让攻击者学到的位置映射在部署时失效”。

## 5. Rotation 强度的 dose-response

α = 走“类位置 + mapping rotation”的 flow 比例；其余 flow 从全局池随机抽位置（边际加权匹配）。

### CIC

| α | position-only | LR | RF | MLP |
| ---: | ---: | ---: | ---: | ---: |
| 0.00 | 0.114 | 0.663 | 0.830 | 0.777 |
| 0.25 | 0.083 | 0.635 | 0.819 | 0.765 |
| 0.50 | 0.052 | 0.600 | 0.818 | 0.763 |
| 0.75 | 0.029 | 0.495 | 0.662 | 0.658 |
| 1.00 | 0.000 | **0.138** | **0.057** | **0.210** |

### UNSW

| α | position-only | LR | RF | MLP |
| ---: | ---: | ---: | ---: | ---: |
| 0.00 | 0.129 | 0.931 | 0.990 | 0.978 |
| 0.25 | 0.099 | 0.911 | 0.990 | 0.970 |
| 0.50 | 0.058 | 0.891 | 0.997 | 0.956 |
| 0.75 | 0.037 | 0.839 | 0.989 | 0.894 |
| 1.00 | 0.000 | **0.263** | **0.405** | **0.376** |

形状：

- **非线性阈值**：α≤0.5 时防御很弱；α≥0.75 开始明显；α=1 最强（尤其 CIC）；
- CIC 对 rotation 更敏感（α=1 接近 chance），UNSW 保留更多残余；
- 位置可预测性与 BA 同向下降，支持“rotation 破坏位置映射”的解释。

## 6. 对研究问题的影响

原来的假设：

> 类特定 trigger placement 改变攻击者能学习的序列表示。

修正为：

> **在固定开销下，class-specific placement 只有在经过 mapping rotation 时才会破坏自适应攻击者学到的位置→类别映射；静态类位置是可学习的，几乎不构成防御。**

这比“位置本身”更具体，也解释了：

- A（placebo code，但位置经 next mapping 旋转）低；
- B（随机位置，无 rotation）高；
- no-rotation 静态类位置高；
- rotation α 曲线非线性。

## 7. 下一步 dose 设计

既然 rotation 是核心，位置策略的 dose 应围绕“rotation + 位置结构”：

| 变量 | 设计 |
| --- | --- |
| rotation 强度 | α=0/0.25/0.5/0.75/1（已完成） |
| 类别内稳定性 | 固定 pair vs 类专属 pool K=2/4/8 每 flow 随机抽，再 rotation |
| 位置池大小 | K=1/2/4/8，控制 overlap |
| 类别间 overlap | 共享比例 β=0/0.5/1 |
| 两事件间距 | gap=2/4/8，合法范围内 |
| position predictability | 每 cell 都报告 position-only BA |
| displacement | 每 cell 报告 mean/median/p95/any，避免位移混淆 |

优先做“类别内稳定性”与“位置池大小”，因为它们直接回答：

> 攻击者难以学习的是 rotation 后的位置映射，还是同一类别内部的位置变化？

## 8. 限制

- Permutation 在 validation 上学习，test 只应用；但 validation 与 test 都来自同一 capture-disjoint split；
- A/D 的 aligned BA 仍低于 B/C，说明 rotation 还破坏了可恢复信息，不只是一次性标签置换；
- α 曲线只有 5 个点，CI 见 JSON；
- 只做了 UNSW/CIC；LR/RF/MLP，位置 code 固定全同。
