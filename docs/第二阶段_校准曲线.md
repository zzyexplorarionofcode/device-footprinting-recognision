# 当前映射标签校准：修正后的结果

> **旧版“曲线平坦”结论已推翻。** 旧脚本只做 day-disjoint + permutation，且 class 列表/样本量处理有 bug；修正后，permutation 只能恢复一部分，linear probe / fine-tune 可以恢复更多。

## 1. 协议

- Arm A（placebo code + 类位置 + rotation）与 D（real）；
- 训练 old mapping；
- test 分成 calibration / eval：
  - `days`：按天不相交；
  - `random`：同一天内按类分层随机 30/70；
- 方法：
  - **permutation**：n 个当前标签估 Hungarian `pred→true`，应用到 eval；
  - **probe**：只用 n 个当前标签训练 LR；
  - **fine-tune**：old 全量 + n 个当前标签，calibration 权重 = len(old)/n；
- 重复 20 次，报告均值。

## 6. 结论

1. **Rotation 不是纯标签置换。**
   - permutation 只能恢复到 0.44–0.51；
   - 说明 traffic 表示本身也被改变，单纯重映射标签不够。

2. **带标签当前样本可以显著恢复，但需要数百级样本。**
   - probe/fine-tune 在 n=256–1024 达到 0.58–0.94；
   - random split 高于 day-disjoint（UNSW 0.856 vs 0.581；CIC 0.941 vs 0.887）；
   - CIC 比 UNSW 更容易恢复。

3. **probe 有时比 fine-tune 更好**：
   - 旧模型的偏差可能拖累 fine-tune；
   - 少量当前标签从头训练一个线性 probe，反而更适应新映射。

4. **攻击者的适应成本是“样本量”而不是“是否可能”。**
   - 有足够当前标签，rotation 可以被重新学会；
   - 因此时间序列实验应重点测 T_τ/J(H)，而不是单点 BA。

## 7. 限制

- 只做 LR；RF/MLP 未做；
- 重复 20 次，CI 可再加；
- n 抽样未严格按类分层（小 n 可能缺类）；
- fine-tune 是简单加权拼接，不是真正的增量学习；
- 只有 A/D 两个 arm；
- CIC calibration 只有 22 天，day-disjoint 的日期数少。

## 8. 对时间序列实验的意义

- 校准曲线说明：攻击者可以用当前标签做 probe/fine-tune，而不是只估置换；
- 因此时间矩阵里的 warm-start 应包含：
  - permutation-only；
  - probe on recent labels；
  - fine-tune on recent labels；
- 只测“从头训练”会低估攻击者的适应能力。
