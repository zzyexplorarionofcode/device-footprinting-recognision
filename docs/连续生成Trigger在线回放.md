# 连续生成新 Trigger 的在线回放

## 协议

- 比较 Stationary IID、原六状态库内 Nonstationary、Continual New-Trigger。全部复用 UNSW8 的 150 个观测日、相同热身流、Calibration/Blind 索引、六段边界及每个观测日日终释放的 8 个设备标签。
- 连续生成策略每 25 个观测日更换一次码本。三次回放分别预先指定生成种子 5100–5105、5106–5111、5112–5117，对应既有的基线 seed 0、1、2。沿用迁移实验生成器，随机改变 Trigger 位置、包长、gap。固定 Mapping 0、两包 Trigger、三包 Weakener、Padding、jitter 和预算分区。候选全部进入评分，配置和 jitter 由现有校验器验证。逐流核对各策略的实际字节、时延和 dummy 成本。
- 攻击者使用累计 LR 或过去 14 个日历日的滑动 LR，保留共同热身的标准化器。各段不断档积累新标签，训练仅使用早于当日 Blind 的标签。主指标为 150 个逐日 Post BA 的等权平均。两种库内策略复用既有完整攻击结果，同时重建同一防御输入用于仅段内标签的对照。
- 切换冲击在第 2–6 段首日测量。用同一批 Blind 原始流生成上一段与本段配置的防御流量，对同一冻结模型评分。报告新配置减旧配置的 BA，负值表示切换压低旧模型性能。首段无上一在线配置，排除。
- 历史价值是完整训练规则的 Post BA 减仅用本段已到达标签的 BA。累计和滑动对照使用相同类型的更新规则与同一个历史标准化器，差异来自有标签训练集是否允许使用此前各段数据。段内标签不足两类时结果留空。滑动窗口过去 14 日均已落在当前段内时，两臂通常使用相同训练数据。该差值仅衡量历史标签的边际价值。
- 防御端需要可信设备类别来源，离线回放以数据集设备标签模拟。攻击者不使用真实 Mapping 或码本参数。三个生成序列与对应的基线 State 随机种子配对，跨重复变化包含序列和基线状态抽样两部分。同一 UNSW8 时间段的结果用于验证是否存在可重复的序列效果。

## 复现

```powershell
python -X utf8 -B -m scripts.continual_new_trigger --dataset data/processed/unsw_main8_v1/flows_unsw_8class.npz --config configs/methods/fade_unsw8_pos_v2.json --pilot artifacts/es/online_nonstationary_s0.json --baseline artifacts/es/online_nonstationary_s0.json --output-log artifacts/es/continual_new_trigger_s0.json
```

其余两次只修改 baseline 和 output-log 的 seed 后缀，pilot 始终使用首轮 seed 0。

## 判读

连续新 Trigger 在三条序列中均反复制造切换冲击。累计 LR 的冲击未随段序单调减弱，但全期 BA 平均高于两条基线，仅一条序列在累计 LR 下低于两基线。滑动 LR 在三条序列均高于两基线。32 标签时，历史标签通常仍有正向价值，新 Trigger 下部分段的历史优势缩小，累计 LR 最后一段三序列平均为负。由此只能确认历史收益依赖当前段，不能推断历史信息普遍失效。库内基线在段内逐流随机，新 Trigger 在段内共享一个固定码本与 Mapping。全期差值是完整策略的联合效应，未隔离段内随机性和生成新码本的贡献。当前不启动 PPO。

## 补充配对：新码本 + 段内 Per-flow

三条序列中，两类 LR 的全期 BA 都低于新码本固定 Mapping 版，也都低于库内 Nonstationary。对同样逐流均匀 Mapping 的 IID，累计 LR 三次均降低约 0.028–0.036，滑动 LR 两次降低、一次上升。加入逐流随机化后，累计 LR 的五次平均切换冲击都比固定 Mapping 版小，但全期 BA 更低。配对结果支持两个时间尺度的组合在当前 UNSW8 协议下有效，累计 LR 的证据强于滑动 LR。三个序列共用同一个时间段，实验没有独立估计两个因素的统计交互，也没有在新数据上验证。
