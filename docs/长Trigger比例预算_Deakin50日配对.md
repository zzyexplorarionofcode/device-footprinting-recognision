# 长 Trigger 比例预算：Deakin10 50 日配对评价

## 问题与冻结协议

在 Full New5 的 T1_W3、五个 dummy、六 State 逐流均匀 IID、五日码本刷新、位置及 Gap 不变的前提下，检验长流额外字节是否有助于扰乱可观测长度统计，以及将相同额外字节集中到一个 Trigger 是否优于分散到两个 Trigger。A 是原 Full New5；B 将额外字节随机分配给两个 Trigger；C 将同量额外字节集中到首个可见 Trigger。A 与 B/C 不等开销；B 与 C 逐 flow 的最终 32-event 窗口内新增可见字节严格相等。

只用 4,000 条 warmup flow 冻结比例：真实上行包合法可 padding headroom 的正值中位数为 1,300 B，`r_b=min(0.25,256/1300)=0.196923`。对每条在线 flow，先在防御后 32-event 窗口中统计真实上行包可 padding headroom `P_i`，再取 `min(r_b P_i, 256 B, 首个可见 Trigger 距 1514 B 的空间)`；以预设的 0.5 概率应用。该 `P_i` 是可增加字节空间，并非整条 flow 总字节，也不等于 Trigger headroom。B/C 保留原 Weakener 及原防御预算，在其之外追加字节。

三个配对 seed（0/1/2）使用相同原始 flow、每天 8 个新标签、128 条 Blind、50 个观测日。每日先评分 Blind，随后释放当天标签；累计与 14 日滑动攻击者按同一规则更新。C 为攻击者可观测的 45 维无序统计，D 为原 64 维序列输入；均未使用内部真实包标记训练攻击者。表中数值为三个 seed 的 50 日日均 BA 均值，越低防御越好。

## 预算与解释

三 seed 的 B/C 实际额外可见字节均值分别为 105.745、105.756、104.872 B/flow；逐 flow 完全配对。零额外字节 flow 约占 50.2%（包含预设的 0.5 不加长概率）。平均真实上行可 padding headroom 为 1,693.10 B，比例公式在 Trigger 上限截断前给出的平均许可额外预算为 212.12 B。所有 6,800 条在线 flow 都保留评价，Blind 共 6,400 条/seed。

追加字节明显降低 C 视图 BA，且集中分配在 C-RF 和滑动 C 攻击下提供小幅附加收益。然而这不能直接证明集中分配是整体更强的防御：D 累计 RF 的 A/B/C 分别为 0.5730/0.5820/0.5825，额外字节反而使其识别率上升；D-LR 也没有一致的集中收益。本实验支持“合法比例预算可改变可观测无序长度统计”的有限结论，不支持用 B 或 C 取代 Full New5。三个 seed 共用同一 Deakin10 时间捕获，不能当作三个独立数据集。

## 复现

- 脚本：`scripts/trigger_long_online.py`
- 命令：`python -X utf8 -B -m scripts.trigger_long_online --days 50 --seed 0 --proportional`；seed 依次取 0、1、2。
- 原始结果：`artifacts/es/trigger_long_online_deakin10_50d_s{0,1,2}_proportional.json`，包含逐日 BA、逐 seed 对照与开销审计。
