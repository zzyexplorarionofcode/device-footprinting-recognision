# 静态 vs 动态：同预算、零标签攻击者

UNSW8 150 观测日，seed 0；初始 20 日热身 4000 标签训练后冻结，攻击阶段 **0 新标签**；同一 Blind、同一 D/C 特征。

## 臂

| 臂 | 码本 | State | 附加开销 |
| --- | --- | --- | --- |
| No-defense | 无 | 无 | 0 |
| Fixed-map | 固定首套码本 | 固定单一 mapping | T1_W3 |
| Fixed-codebook-IID | 固定首套码本 | 逐流均匀 IID | T1_W3 |
| Full-New5 | 每 5 观测日刷新 | 逐流均匀 IID | T1_W3 |

Fixed-map / Fixed-codebook-IID / Full-New5 使用相同 T1_W3 配置；No-defense 为零开销参照。

## 平均 Post BA

| 臂 | D/LR | D/RF | C/LR | C/RF |
| --- | ---: | ---: | ---: | ---: |
| No-defense | 0.634 | 0.663 | 0.415 | 0.520 |
| Fixed-map | 0.649 | 0.663 | 0.519 | 0.503 |
| Fixed-codebook-IID | 0.603 | 0.630 | 0.519 | 0.503 |
| Full-New5 | **0.575** | **0.609** | 0.519 | 0.503 |

## 50 日分块（D/LR）

| 臂 | 1–50 | 51–100 | 101–150 |
| --- | ---: | ---: | ---: |
| No-defense | 0.843 | 0.554 | 0.405 |
| Fixed-map | 0.852 | 0.564 | 0.436 |
| Fixed-codebook-IID | 0.820 | 0.527 | 0.354 |
| Full-New5 | **0.782** | **0.502** | **0.336** |

## 解释

1. **静态固定 mapping 几乎没有防御收益**：D/RF 与 No-defense 相同（0.663），D/LR 甚至略高。
2. **逐流 IID State 本身有收益**：固定码本 + IID 比 No-defense 低约 3–4 pp。
3. **Full New5 在 IID 上再降约 2–3 pp**：
   - D/LR 0.603 → 0.575（−2.9 pp）
   - D/RF 0.630 → 0.609（−2.1 pp）
4. **相对完全静态 Fixed-map**：
   - D/LR 0.649 → 0.575（−7.4 pp）
   - D/RF 0.663 → 0.609（−5.4 pp）
5. **C 视图三个防御臂完全相同**：C 只看下行和 >256B 长度统计，Trigger 码本刷新不在 C 的输入里；因此 C 不能证明动态码本增量，只说明稳定残余仍在。
6. **动态优势随时间是持续的**：D/LR 三个 50 日块都低于 Fixed-codebook-IID，但幅度不大（1.8–3.8 pp）。

## 结论

> 在相同 T1_W3 开销、相同零标签攻击者下，Full New5 相对固定码本 + IID 有约 2–3 pp 的额外 BA 降幅；相对完全静态 fixed-map 有约 5–7 pp；相对无防御有约 5–6 pp（但无防御是零开销）。动态码本的价值存在，但不是数量级提升，且只体现在 D 视图；C 视图对码本刷新不敏感。

## 限制

- 仅 seed 0；
- C 视图定义不含 Trigger 长度区间，故对码本刷新天然不敏感；
- 零标签攻击者使用初始 defended 知识，不代表低标签适应；
- 动态优势幅度小于“逐流 IID vs 固定 mapping”的差异。
