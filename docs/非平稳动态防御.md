# 非平稳动态防御 · 在线回放协议

本轮冻结既有 Fixed / Periodic / Per-flow 机制结果。主要比较 Nonstationary 与 Stationary IID 的适应曲线。Static 和 Periodic 是辅助参照。

## 防御与配对

- 复用 UNSW8、FADE pos v2、六个 Mapping State 和 32-event 窗口。逐流断言三种成本指标在四策略间相等，单位依次为 B、秒、dummy 数量。
- 共用相同的原始流、Calibration/Blind 行索引和设备标签。每条原始流有一个固定均匀随机数，策略按各自概率向量将其变换成 State。抽样、State 随机数、调度用独立种子流。
- 前 20 个有记录的日期为历史热身，从中抽取至多 4,000 条 IID 防御流，所有攻击者共享。在线区间为之后连续 150 个有记录的日期，每 25 个观测日一个 regime。真实经过时间用 UTC 日历日计，包含无观测日期的间隔。
- Static 在线全程保持一个随机 State，Periodic 每个 regime 使用一个共享 State 并按序轮换。IID 每流独立均匀。Nonstationary 每流仍独立采样，regime 内使用固定非均匀混合概率，regime 边界换概率。六组向量由三个随机排列及各自的补向量组成，对观测日等权平均恰为均匀分布。由于每天的 Blind 样本数可能不同，按流合并的边际混合比例可有偏差。
- 首轮在每个 Nonstationary 切换日把同一批 Blind 原始流分别用新旧混合概率渲染，复用逐流随机数。比较冻结 LR 在这两份流量上的 BA，并按设备类别报告标准化特征均值的 RMS 差。该诊断检验策略切换能否改变可观测特征及其影响方向，覆盖了条件均值这一部分。

## 在线攻击与时间

- 攻击者仅看防御后的特征及获准的设备标签，使用端到端 LR，无 Mapping State 监督。特征标准化器由共享热身拟合并冻结。累计 LR 使用全部既往有标签样本，滑动 LR 使用过去 14 个日历日的有标签样本。窗口不足两类时回退到共享热身模型，并记录回退。
- 每个观测日独立于标签抽取 8 条可标注流及至多 128 条互斥 Blind flows。用既往日期的数据更新 LR，再对当日 Blind 评分。当日 8 个标签在当日结束后释放，首次影响下一观测日。代码核对流首包和末包均在 capture 标注的 UTC 日期内。Blind 标签仅用于评分及离线漂移诊断。
- 每个 regime 首日锁定 pre 模型。随后每天将该冻结模型与当日更新后的 post 模型评在同一批新 Blind flows 上。首日 post 可用的新 regime 标签为 0。后续的 pre/post 差值给出固定该日测试类别构成时的更新收益。
- 日 BA 对当日 Blind 中出现的类别等权，未被模型见过的类别以零召回计。期限内累计表现用日 BA 的等权平均表示。首轮阈值预设 BA 0.70，记录首次连续两个观测日达标的起点、已到手标签和日历耗时；第二个观测日用于确认。窗口内未达到的项记为右删失。不同日期的类别组成会变化，阈值时间是探索性结果。

## 固定调度的 State RNG 确认性复验

Seed 0 复用原试验日志。Seed 1、2 使用 --replay 锁定同一批原始流、日期、候选映射、六段混合概率及历史热身流量的 State。每次只重抽在线逐流 State，IID 与 Nonstationary 共用同一行的均匀随机数。阈值仍为 0.70。

### 标签时间审计

每个调度段的首日用严格早于首日的标签拟合 pre 模型，随后保持该模型对象冻结。post 每日重新拟合，历史缓冲中只允许过去日期的样本。当日 Calibration 的 8 个标签在当日 Blind 评分后加入缓冲。检查所有首日 pre = post、已到手的新段标签数为 0，逐日标签总数与释放账本一致。连续达标按相邻两个观测日确认，表中报告起点的 UTC 日历耗时及当时的已释放标签。

## 下一轮预注册：有限调度对照

### 冻结基线与评价目标

冻结首轮六段调度及 seed 0、1、2 的 IID / Nonstationary 配对日志。后续调度比较直接复用这两个对照。三份日志保留在 `artifacts/es/online_nonstationary_s{0,1,2}.json`。本节先确定实验条件，尚无新增调度的结果。

**主目标是降低整个 150 个观测日内持续更新的攻击者日均 BA。** 累计 LR 为主分析，14 日滑动 LR 单独报告，用来检验效果是否随历史利用方式改变。按日期对同一批 Blind 原始流配对，先在每个 seed 内对 150 个逐日 BA 差等权平均，再报告三个 seed 的差值与范围。负值表示调度降低攻击 BA。流量预算通过逐流一致性断言固定。

切换后前三个日历日的 BA 是短时防御指标，旧混合反事实衡量切换对同一冻结模型的即时冲击。仍用 BA 0.70 报告首日、首次和连续达标的时间与标签数。首日已达标单列，未达标记为右删失。不同周期的恢复对照限制在共同的前五个观测日，日历耗时仍按真实日期计算。

### 固定候选

记首轮日志的六组概率向量依时间顺序为 `p0, ..., p5`，均匀向量为 `u`。三项变体各自与原调度配对，另与 Stationary IID 比较。总计五个条件。

| 条件 | 每段观测日 | 概率向量与顺序 | 对照问题 |
| --- | ---: | --- | --- |
| Stationary IID | 150 | 全期用 u | 稳定随机化参照 |
| 原调度 | 25 | 复用 p0 到 p5 的原顺序 | 已冻结的非平稳参照 |
| 短周期 | 5 | 以原顺序重复完整六向量序列五次 | 提高切换频率 |
| 低集中度 | 25 | 原顺序，每个 pi 替换为 (pi + u) / 2 | 减弱混合权重偏离 |
| 固定顺序 | 25 | 保持六组原向量，按最大概率所在的 State 编号升序排列，并用原索引打破平局 | 改变权重切换路径 |

每个非平稳候选对 150 个观测日等权后的目标混合均为 u。短周期同时缩短同一概率向量的重访间隔。固定顺序改变相邻向量的跃迁幅度和发生日期，结果按这两条具体路径解释。各策略复用已有日志对应的 State seed、逐流随机数、历史热身、Calibration/Blind 索引及每日 8 标签的释放规则。攻击者输入仍限于防御后特征与历史设备标签。

三项对照全部报告，包括逐 seed 的全期差、早期差及切换反事实。早期结果使用该策略实际切换日期上的 IID 作配对参照，周期不同带来的日期集合差异单独标注。三 seed 结果只用于检验固定样本和固定候选下对 State 抽样的敏感性。同方向差异若集中在个别调度段或只出现在累计 LR，结论限定到对应阶段或攻击者。后续若有候选显示可重复的全期差异，再用独立时间段或预设调度路径检验泛化。

### 本轮决策

短周期对累计 LR 的全期 BA 在三个 seed 都低于 IID，幅度为 0.0001–0.0049，但相对原调度只有一个 seed 更低。滑动 LR 下的全期差值方向不一致。低集中度和固定顺序对累计 LR 的全期差值跨 seed 变号。短周期覆盖了 54.7% 的观测日，但每次切换的前三天平均效果弱于原调度。共同五日窗口内未见一致的恢复延迟。该结果支持保留短时冲击结论，尚不足以启动 RL 调度优化。
